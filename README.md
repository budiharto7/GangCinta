# 🏘️ Gang Cinta - Sistem Informasi Warga

Website sistem informasi warga RT/RW berbasis web modern.

## ✨ Fitur

- 🔐 Login multi-level (Admin, Ketua RT, Warga)
- 👨‍👩‍👧‍👦 Manajemen data warga & Kartu Keluarga
- 📷 Upload & scan KK otomatis (OCR)
- 💬 Live chat antar warga
- 📊 Dashboard statistik RT
- 🌙 Dark/Light mode
- 📱 Responsive mobile-friendly

## 🚀 Tech Stack

- **Frontend:** React 18 + Vite + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** JSON file (lokal)
- **OCR:** Tesseract.js

## 🛠️ Cara Jalankan Lokal

```bash
# Install dependencies
npm install

# Jalankan dev server (frontend + backend bersamaan)
npm run dev
```

Frontend: http://localhost:3000  
Backend API: http://localhost:3001

## 🌐 Deploy

- **Frontend:** Netlify (auto-deploy dari GitHub)
- **Backend:** Diperlukan server Node.js terpisah
